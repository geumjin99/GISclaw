          A model served on this computer — Ollama, LM Studio, vLLM — keeps the whole
          analysis here: nothing is sent to a provider, nothing is billed. Small models plan
          multi-step work less reliably than the hosted flagships; the ones recommended below
          have completed this project's benchmark tasks. Context length matters most:
          a run needs at least 8,192 tokens, or the server
          silently drops the instructions off the front of the prompt.
